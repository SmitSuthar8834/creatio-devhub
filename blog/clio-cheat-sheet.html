clio cheat sheet: the commands Creatio developers use most

By Smit Suthar · October 24, 2026 · 3 min read
Short answer

clio is the open-source command line for Creatio, installed with dotnet tool install clio -g. Register an environment once with clio reg-web-app, then add -e name to every command. The most used commands are pull-pkg and push-pkg for packages, restore-workspace and push-workspace for Git, and compile-configuration, clear-redis-db and restart-web-app after a deploy.

clio is the open-source command-line tool for Creatio, maintained by Advance Technologies Foundation. It has well over a hundred commands; these are the ones that cover most days. Everything below was checked against clio 8.1. Run clio help for the full list and clio <command> --help for any command's options.

Install and update

dotnet tool install clio -g
clio update-cli
clio info

clio needs the .NET SDK. clio info shows the clio, cliogate and .NET runtime versions.

Environments

CommandWhat it does
clio reg-web-app dev -u URL -l USER -p PASSRegister an environment, or update its settings.
clio ping-app -e devCheck clio can reach the environment and sign in.
clio open-web-app -e devOpen the environment in your browser.
clio install-gate -e devInstall or update cliogate, which SQL, workspaces and log streaming need. Restarts Creatio.
clio get-info -e devShow system information for the instance.
clio unreg-web-app devRemove a registered environment.

Careful with clio list-environments (also clio env): it prints your saved environment settings, which can include credentials. Don't paste its output into tickets or chats.

Packages

CommandWhat it does
clio list-packages -e devList packages in the environment.
clio pull-pkg UsrOrders -e devDownload a package to disk.
clio push-pkg UsrOrders -e testInstall a package folder or .zip/.gz. Backs up first unless --skip-backup true.
clio compile-package UsrOrders -e devCompile one package.
clio lock-package / clio unlock-packageLock or unlock a package.
clio get-pkg-version / clio set-pkg-versionRead or set a package version.
clio delete-pkg-remote UsrOrders -e devDelete a package from the environment.

Applications

CommandWhat it does
clio list-apps -e devList installed applications.
clio deploy-application MyApp -e dev -d testCopy an application between environments.
clio download-application / clio install-applicationDownload an application package, or install one from a file.
clio uninstall-app-remoteUninstall an application.

Workspaces and Git

CommandWhat it does
clio create-workspace -e devCreate a workspace in the current folder from the environment's editable packages.
clio restore-workspace -e devDownload the workspace's packages again (alias pullw).
clio push-workspace -e testPack and install the whole workspace (alias pushw).
clio publish-appPublish a workspace to a ZIP archive.

After a deploy: compile, cache, restart

clio compile-configuration -e test
clio clear-redis-db -e test
clio restart-web-app -e test --wait-ready

Run them in that order. clio last-compilation-log -e test shows the last compile's log. clear-redis-db only clears the cache and restart-web-app only restarts, so you usually want both.

Data, settings and feature toggles

CommandWhat it does
clio execute-sql-script "SELECT ..." -e dev -v csv -d out.csvRun SQL and save the result (needs cliogate 2.0.0.41+).
clio set-syssettingGet or set a system setting.
clio set-feature UsrMyFeature 1 -e devTurn a feature toggle on (0 turns it off).
clio create-data-bindingBind lookup data to a package so it deploys with it.
clio save-state / clio show-diffSave an environment's state to a manifest, and compare environments.

Local Creatio

CommandWhat it does
clio deploy-creatio --zip-file C:\Builds\creatio.zipInstall Creatio from a distribution zip (IIS on Windows).
clio uninstall-creatio -e localRemove a local instance: site, database and files.
clio start / clio stopStart or stop a local Creatio application.
clio hostsList Creatio hosts and their status.

Watching what happens

clio listen streams Creatio's log over a WebSocket (needs cliogate), and clio healthcheck runs Creatio's health checks.
