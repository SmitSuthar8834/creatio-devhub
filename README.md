# Companion for Creatio

*Formerly **Creatio DevHub** — renamed in v0.12.10. Same app; existing installs update in place.*

A cross-platform (Windows & macOS) desktop workbench for Creatio developers — a
visual, job-based interface over [clio](https://github.com/Advance-Technologies-Foundation/clio)
and Git for managing environments, packages, applications, and source-controlled
workspaces. Companion for Creatio does not connect directly to Creatio APIs and
does not store Creatio passwords; environment registration and credentials remain owned by clio.

## Source code

The source is maintained in a **private repository**. This public repository
hosts the **releases**, the signed **auto-updater feed**, the **website**, and
**issue tracking**.

## Download

- Website: <https://smitsuthar8834.github.io/creatio-devhub/>
- All releases: <https://github.com/SmitSuthar8834/creatio-devhub/releases>
- Latest: <https://github.com/SmitSuthar8834/creatio-devhub/releases/latest>

Windows ships signed `.exe` / `.msi` installers with auto-updates. macOS ships a
universal `.dmg` (Apple Silicon + Intel); it is not yet Apple-notarized, so the
first launch needs a one-time right-click → **Open**.
